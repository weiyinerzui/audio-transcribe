audio-transcribe  使用说明
================================================

这是一个「免安装」版本：不用装 Python，不用装 ffmpeg，
双击一个文件就能用。


一、怎么开始
------------------------------------------------

1. 先把整个压缩包「全部解压」到一个文件夹。
   建议放 D:\audio-transcribe 这种纯英文路径。

   ⚠ 不要只把里面的文件拖出来，也不要放在
     「桌面\新建文件夹 (2)\...」这种带括号的路径。

2. 双击「启动.bat」。

3. 等几秒，浏览器会自动打开一个页面。
   看到「新建转录」就说明成功了。

4. 这个黑色窗口不要关。关掉服务就停了。


二、怎么转录
------------------------------------------------

方式一：本地文件
  点「新建转录」→「选择文件」→ 挑你的音频或视频
  → 点「开始」→ 等进度条走完 → 点「查看结果」

  支持的格式：mp3 wav m4a flac aac ogg opus wma
              mp4 mkv mov avi webm flv ts m4v

方式二：网页链接
  点「新建转录」→「网页链接」→ 把 B 站等平台的
  视频地址粘进去 → 点「开始」

  支持 B 站、YouTube、抖音、小红书、快手等
  （部分平台要登录 Cookie，见第六节）


三、默认用的是免费方案
------------------------------------------------

默认引擎是「必剪（bcut）」，走 B 站的免费云接口，
不需要任何 API Key，也不吃你电脑性能。

想用 AI 把文稿里的「嗯、那个、就是说」清理掉，
需要在「服务商设置」里填一个文本模型的地址和 Key。
不填也能用，会自动降级成本地规则清理（效果也不错）。

本地模型（faster-whisper）是可选的，要另外下载模型文件，
第一次用建议先不折腾。


四、你的数据存在哪
------------------------------------------------

全部在刚才解压的那个文件夹下的 data 目录里：

  data\tasks.json      任务历史
  data\outputs\        转录好的文稿（srt / txt / json）
  data\uploads\        你上传的原始音视频
  data\models\         下载的本地模型（如果下了）
  data\server.log      运行日志，出问题时看这个

想搬到别的电脑，把整个文件夹拷过去就行。
想彻底清理，直接删掉 data 目录。

⚠ 你在「服务商设置」里填的 API Key 只存在浏览器里，
   不写进任何文件，所以换浏览器或清缓存要重填。


五、怎么关掉
------------------------------------------------

双击「停止.bat」，或者直接关掉那个黑色窗口。

如果关窗口后网页还能打开，说明进程没退干净，
双击一次「停止.bat」即可。


六、B 站以外的平台
------------------------------------------------

知乎、小红书、抖音这类需要登录才能看的，
要在「服务商设置」里填对应平台的 Cookie。

获取方法：浏览器登录网站 → 按 F12 → 
Network 标签 → 随便点一个请求 → 找到 Cookie 那一行
→ 整行复制粘贴进去。

Cookie 等同于你的登录凭证，只填在你自己电脑上，
不会上传到任何服务器。


七、打不开怎么办
------------------------------------------------

问题：双击后闪一下就没了 / 提示端口被占用
  看 data\server.log 的最后几行。
  最常见是上次的窗口没关，双击「停止.bat」再启动。

问题：浏览器没自动打开
  手动开浏览器，地址栏输入 http://127.0.0.1:8787

问题：提示找不到 python\python.exe
  压缩包没解压完整，重新完整解压一次。

问题：杀毒软件报毒
  这是误报（打包后的 Python 常见）。
  加信任后重试，或者用 npm/pip 方式安装。

问题：卡在「正在启动服务」
  等满 60 秒会打印日志。
  多半是路径带中文，换个纯英文路径重试。
